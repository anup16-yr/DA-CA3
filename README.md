# House Price Prediction

A beginner-level Data Analytics and Machine Learning project that predicts house prices using **Linear Regression**.

## Dataset
- Source: [Kaggle – Housing Prices Dataset](https://www.kaggle.com/datasets/yasserh/housing-prices-dataset)
- File: `Housing.csv`
- Records: 545

## Technologies Used
- Python
- Google Colab
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn

## Project Workflow
1. Data loading and exploration
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Data visualization
5. Linear Regression model training
6. Model evaluation and prediction

## Visualizations
- Price distribution
- Area vs Price
- Bedrooms vs Price
- Correlation heatmap
- Parking vs Price
- Actual vs Predicted Prices
- Residual Plot

## Evaluation Metrics
- MAE
- MSE
- RMSE
- R² Score

## Files
- `House.price.prediction.ipynb` – Complete project notebook
- `model_performance.csv` – Evaluation results
- `predictions.csv` – Actual and predicted prices
- `visualizations/` – Generated graphs
